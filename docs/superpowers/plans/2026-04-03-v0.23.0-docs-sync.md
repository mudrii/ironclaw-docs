## Release Summary (What Changed)

### v0.20.0 (2026-03-19)
- Self-repair `stuck_threshold` wire (#712)
- FaultInjector testing framework for StubLlm (#1233)
- Unified settings page with subtabs (#1191)
- MiniMax default model upgrade to M2.7 (#1357)
- Fixes: Telegram E2E nav, routine lifecycle, debug_assert guards, MCP retry, Telegram polling, LLM retry-after caps

### v0.21.0 (2026-03-20)
- Structured fallback deliverables for failed/stuck jobs (#236)
- LRU embedding cache for workspace search (#1423)
- Webhook callbacks for relay events (#1254)
- Generic hosted OAuth and MCP auth (#1375)
- Fix: auto-approve for credentialed HTTP requests (#1257)

### v0.22.0 (2026-03-25) — MAJOR
- Per-tool reasoning through provider, session, and all surfaces (#1513)
- `ironclaw models` subcommands: list/status/set/set-provider (#1043)
- `ironclaw hooks list` subcommand (#1023)
- Multi-tenant auth with per-user workspace isolation (#1118)
- Multi-scope workspace reads (#1117)
- Complete UX overhaul — design system, onboarding, web polish (#1277)
- Gemini CLI OAuth integration with Cloud Code API (#1356)
- Graduated command approval: Low/Medium/High risk levels (#368)
- Message queuing during active turns (#1412)
- GitHub Copilot as LLM provider (#1512)
- OpenAI Codex (ChatGPT subscription) as LLM provider (#1461)
- Layered memory with sensitivity-based privacy redirect (#1112)
- Public webhook trigger endpoint for routines (#736)
- Light theme with dark/light/system toggle (#1457)
- `stuck_threshold` activation for time-based stuck job detection (#1234)
- Chat onboarding and routine advisor (#927)
- Text setup fields in web configure modal (#496)
- Fixes: LLM user-message ordering, owner-scoped startup, stream_token gate, Mistral tool call IDs, MCP 202 acknowledgements, XML tool-output escape, OAuth state validation, oneOf/anyOf/allOf coercion, MCP client persistence, rustls-webpki vuln, libSQL vector search, f32→f64 temperature, SSRF embedding validation

### v0.23.0 (2026-03-27)
- Complete multi-tenant isolation phases 2-4 (#1614)
- MCP: handle 202 Accepted + wire session manager for Streamable HTTP (#1437)
- Direct hosted OAuth callbacks with proxy auth token (#1684)
- Fixes: routine delete name recovery (#1108), channel-relay auth (#1681), truncated tool calls on Length (#1631), XML tool-call recovery filtering (#1641)
